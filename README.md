# Esp-Dsp

Implementation of a 4 channel DSP for a 3-way stereo speaker.

Dual core approch:
Core0: Volume controll
Core1: I2S and iir filters

Main file: main/i2s_std_example_main.c
Script for iir parameter calculation: parameterCalculator.py
Documentation created for university projekt: Studienprojekt.pdf, Project presentation.pptx
